# 🚁 Вертолет-пожарный

Консольная игра на Python, где вы управляете вертолетом-пожарным и тушите пожары в лесу.

## 🎮 Игровой процесс

Вы управляете вертолетом, который может:
- Летать по полю (WASD)
- Набирать воду с рек (E)
- Тушить горящие деревья (F)
- Посещать госпиталь для лечения (H)
- Покупать улучшения в магазине (M)

## 📋 Цели игры

1. **Тушить пожары** - получайте очки за каждое потушенное дерево
2. **Предотвращать распространение огня** - если дерево сгорит, вы теряете очки
3. **Выживать** - у вертолета есть 3 жизни
4. **Улучшать вертолет** - покупайте улучшения в магазине

## 🌤️ Погодные условия

- **Солнечно** - обычные условия
- **Дождливо** - пожары тухнут медленнее
- **Гроза** - молнии могут поджигать деревья

## 💾 Сохранение игры

Игру можно сохранить (S) и загрузить (L) в любой момент.

## 🚀 Запуск игры

```bash
python game.py
